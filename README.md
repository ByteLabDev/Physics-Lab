# Physics Lab

Physics Lab was a game that I had started working on some time in 2020-2021. In the latest build, you can:
- Spawn items (e)
- Enable/disable nametags (right click menu)
- Change gravity
- Change timescale (q)
- Switch between light/dark mode
- Throw and hit objects with particle effects

There's an issue where the main menu buttons jump around. You have to quickly press on 'sandbox' to load the game. The other menu options are placeholders, they do not work.

Some files may be missing, and the game might not load into Unity. This repository was only uploaded to display my personal growth, and will not be maintained.
